# Дневник питания

Приложение на Java для учёта питания и расчёта КБЖУ.

##  Стек
- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- MySQL
- Thymeleaf
- Chart.js.
- Lombok

##  Функционал
– регистрация новых пользователей и аутентификация существующих для
обеспечения персонального доступа к данным;
– заполнение и редактирование личного профиля пользователя, включая изменение персональных данных, 
показателей и замеров, необходимых для отслеживания изменения состояния здоровья и организма;
– добавление, просмотр и удаление записей о приемах пищи с возможностью указания отдельных продуктов или готовых рецептов;
– ведение общей базы продуктов питания с возможностью добавления новых и указания их пищевой ценности;
– ведение общей базы рецептов с возможностью создания и сохранения пользовательских индивидуальных рецептов;
– удаление рецептов из общей базы данных только при условии, что действие выполняется пользователем, являющимся создателем данного рецепта;
– автоматический расчет калорийности и содержания БЖУ на основе выбранных продуктов и рецептов;
– хранение истории приемов пищи и предоставление доступа к ранее внесенным данным;
– формирование аналитических отчетов за выбранную дату или период времени с отображением статистики потребления калорий и баланса БЖУ;
– предоставление пользователю информации о динамике изменения массы тела и других показателей, основываясь на сохраненных данных.

##  Что было сделано
- Реализована система регистрации пользователей на основе Spring Security
с хешированием паролей по алгоритму BCrypt.
- Разработан функционал ведения пищевого дневника с возможностью добавления записей о продуктах и рецептах с группировкой по типам приемов пищи.
- Реализовано управление профилем пользователя и историей замеров тела, включая расчет индекса массы тела и отображение динамики веса в виде графиков.
- Создан модуль рецептов с автоматическим расчетом КБЖУ на 100 грамм готового блюда, а также поддержкой загрузки изображений.
- Разработана система формирования суточных и недельных отчетов о питании с визуализацией данных с помощью библиотеки Chart.js.

##  Как запустить
1. Установить Java [версия]
2. Скомпилировать: `javac Main.java`
3. Запустить: `java Main`
